PBZQuickSave v0.8.1 — 完整安装包
==================================

里面包含：
  · UE4SS（PBZ 专用版 v3.0.1-1195）—— 运行环境
  · PBZQuickSave 模组 —— 功能本体

不需要再去下载任何东西。


【这个包能干什么】

  F8    存档 + 记录当前位置
  F9    传送回记录的位置
  F10   读档 + 传送（读档部分尚未打通，目前只传送）

  实际效果：F8 记个点，走远了按 F9 就瞬移回去。跨游戏重启也认。


==================================================
安装流程
==================================================

第 0 步：完全退出游戏
    任务管理器里确认没有 PBZ.exe 在跑，否则文件会被占用。


第 1 步：解压
    不要把压缩包拖进游戏目录，也不要直接在压缩包里双击脚本。
    先整个解压到任意位置（桌面就行）。
    解压后应该能看到：
        install.bat
        install.ps1
        安装说明.txt
        payload\


第 2 步：找到游戏目录
    从 Steam 装的，路径一般是：
        ...\steamapps\common\PBZ\platform\steam
    这个目录里应该有 PBZ.exe。

    最省事：Steam 库 → 右键《影之刃零》→ 管理 → 浏览本地文件，
    然后再进 platform\steam 这一层。

    注意不是 PBZ 那一层，是它下面的 platform\steam。


第 3 步：双击 install.bat
    它会：
      ① 自动去找游戏目录（找不到会让你粘贴路径）
      ② 备份你原有的 dwmapi.dll 和 ue4ss 目录（加 .bak 后缀）
      ③ 把 payload 里的东西复制进去
      ④ 逐个检查是否到位

    看到三行 [OK] 和「安装完成」就成功了。


第 4 步：启动游戏
    正常从 Steam 启动。
    会弹出一个黑色控制台窗口 —— 那是 UE4SS 的日志窗口，正常现象。
    进入关卡后按 F8 试一下。


==================================================
如果 install.bat 双击没反应
==================================================

可能是系统禁用了 .bat 或者杀软拦了。手动执行也可以：

  1. 在解压出来的文件夹里，按住 Shift + 右键 → “在此处打开 PowerShell 窗口”
  2. 输入：
        powershell -ExecutionPolicy Bypass -File .\install.ps1
  3. 回车，按提示操作

或者干脆手动复制（最原始但一定可行）：

  把 payload 文件夹里的两样东西
      dwmapi.dll
      ue4ss\
  整个复制到 ...\PBZ\platform\steam\ 下面（和 PBZ.exe 放一起）。
  如果那里已经有了同名文件，先改名备份再覆盖。


==================================================
卸载
==================================================

删掉这两个：
    ...\PBZ\platform\steam\dwmapi.dll
    ...\PBZ\platform\steam\ue4ss\

如果安装时生成了 .bak 备份，把名字改回去即可。
不修改游戏本体，不动存档。


==================================================
杀毒软件提示怎么办
==================================================

UE4SS 用的是 DLL 注入（和很多单机 mod 框架一样），
Windows Defender 大概率会弹一次提示。这是预期的，不是病毒。

  · 提示“已阻止” → Windows 安全中心 → 病毒和威胁防护 →
    保护历史记录 → 找到这条 → “允许”
  · 提示“未知发布者” → “仍要运行”

UE4SS 是开源项目（KintaroModding/ue4ss，MIT 协议），
本包内 ue4ss\LICENSE 就是它的许可证。


==================================================
已知问题
==================================================

1. F10 读档无效
   游戏提供 GM_LoadGame 和 LoadGame 两个入口，前者传任何槽名都不执行，
   后者需要 LoadGameResultParam 结构体参数，传空表时会在入口静默返回。
   目前 F10 实际只做传送。

2. F8 写的是主存档槽（AutoSave0）
   F8 之后的所有进度，都会被下一次读档抹掉 —— 这是“检查点”的固有含义。

3. 运行中强制存档可能留下边缘状态
   读档后偶见 “SendGameplayEventToActor: Invalid ability system component”
   报错（例如梯子触发失败）。重新进出该区域或重启游戏通常可恢复。
